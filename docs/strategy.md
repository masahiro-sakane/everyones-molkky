# モルック AI投擲助言 戦略ドキュメント

AI助言ロジックの実装・改善のための戦略リファレンス。
「この条件のときはこの行動」という形式で記述する。

---

## 1. 得点システムの基礎

| 倒れたスキットル | 得点 |
|---|---|
| 1本のみ | そのスキットルの数字（1〜12） |
| 2本以上 | 倒した本数（2, 3, 4...） |

- 目標：ちょうど50点
- 50点超過 → 25点に戻る（オーバースコア）
- 3回連続ミス → 失格（そのセット終了）

## 2. スキットル初期配置と優先度

### 初期配置（投擲ラインから約3.5m）

```
前列（手前）
  [ 1 ][ 2 ]

中前列
  [ 3 ][10][ 4 ]

中後列
  [ 5 ][11][12][ 6 ]

後列
  [ 7 ][ 9 ][ 8 ]
```

### 番号別評価

| 番号 | 得点 | 序盤価値 | 終盤価値 | 隣接リスク（初期） |
|---|---|---|---|---|
| 12 | 12 | 高 | 非常に高 | 大（中後列中央、密集） |
| 11 | 11 | 高 | 非常に高 | 大（中後列中央、密集） |
| 10 | 10 | 高 | 高 | 中（中前列、比較的取りやすい） |
| 9 | 9 | 中 | 高 | 小（後列、孤立しやすい） |
| 8 | 8 | 中 | 高 | 小（後列端） |
| 7 | 7 | 中 | 中 | 小（後列端） |
| 6 | 6 | 低 | 中 | 中（中後列端） |
| 5 | 5 | 低 | 中 | 中（中後列端） |
| 4 | 4 | 低 | 低 | 小（中前列端） |
| 3 | 3 | 低 | 低 | 小（中前列端） |
| 2 | 2 | 低 | 調整用 | 小（最前列） |
| 1 | 1 | 低 | 調整用 | 小（最前列） |

**序盤の1本狙い推奨順（精度が高い場合）：12 > 11 > 10 > 9 > 8**

## 3. スコア帯別の基本戦略

### フェーズ1：序盤（スコア 0〜25点）

**方針：スコアを素早く積む。精度に応じて1本 or 複数本を使い分ける。**

```
精度レベル「高」→ 12 > 11 > 10 > 9 の順で1本狙い
精度レベル「中」→ 高得点1本を基本とし、密集があれば複数本も検討
精度レベル「低」→ 密集群を狙い3〜5本確実に倒す

期待値の損益分岐点：
  複数本（3本、成功率80%）の期待値 = 3 × 0.8 = 2.4点
  12番1本の期待値 = 12 × P
  → P > 20%（成功率20%超）なら12番1本狙いが有利
```

### フェーズ2：中盤（スコア 26〜39点）

**方針：1本狙い中心。オーバースコアを意識し始める。**

```
基本：高得点スキットル（10, 11, 12番）の1本狙い
制約：スコア + 狙う番号 <= 50 を必ずチェック
  → スコア 39以上は12番を狙わない（39 + 12 = 51、オーバー）
複数本：原則禁止（オーバースコアリスクが高い）
```

### フェーズ3：終盤（スコア 40〜49点）

**方針：残り点数ちょうどの番号を1本で仕留める。複数本は禁止。**

```
残り点数 = 50 - 自スコア

残り1〜12点 → 対応する番号スキットルを1本狙い
残り13点以上 → 残り点数を超えない最大番号を1本狙い（段階的に積み上げ）

例：スコア = 42（残り8点）
  → 8番を1本狙い（42 + 8 = 50、勝利）
  → 次善：9番以上は危険。7番以下は次ターンへ持ち越し
```

### フェーズ4：オーバースコア後（スコア = 25に戻った）

```
相手スコア >= 40 → 妨害フェーズへ切り替え
相手スコア < 40  → 中盤戦略を再開（序盤には戻らない、25点からスタート）
```

## 4. 1本狙い vs 複数本狙いの判断基準

### 判断フロー

```
スコア >= 40点 → 必ず1本狙い（複数本禁止）
スコア 26〜39点 → 1本狙い（オーバーになる番号は除外）
スコア 0〜25点 →
  投擲者精度 高 → 1本狙い（12 > 11 > 10...）
  投擲者精度 中 → 状況次第（下記の期待値計算）
  投擲者精度 低 → 密集群の複数本狙い
```

### 複数本狙いが有効な条件

- スキットルが3本以上密集している（半径30cm以内）
- 投擲者の1本成功率が30%以下
- スコア 0〜25点の序盤
- ミスカウントが2（失格回避最優先）

## 5. スキットルの狙いやすさ（蓋然性）の評価

AIが助言する際に、スキットルごとの「倒せる可能性」を評価する要素。

### 5-1. 距離による難易度

```
距離 2m以下  → 成功率補正 +20%（非常に近い）
距離 2〜3.5m → 成功率補正 ±0%（標準距離）
距離 3.5〜5m → 成功率補正 -15%（やや遠い）
距離 5m以上  → 成功率補正 -30%（非常に遠い）
```

距離が遠い場合、高得点スキットルより近い低得点スキットルを選ぶことを推奨。

### 5-2. 前後左右の隣接スキットルとの間隔

スキットルが散らばった状態では、狙ったスキットルの周囲の配置が重要。

```
孤立している（最近隣のスキットルまで30cm以上）
  → 1本狙いのリスク低、推奨
  
隣接スキットルが1本ある（15〜30cm）
  → 1本のみを狙うのはやや難しい。投擲角度の調整が必要
  
密集している（2本以上が15cm以内）
  → 1本狙いは困難。複数本になる可能性が高い
  → 複数本狙いとして扱う、またはスキットルの配置変更を優先

縦一列に並んでいる
  → 縦投げが有効（手前1本のみ倒せる）
```

### 5-3. 縦投げの活用

縦投げ（スキットルを縦に持って投げる）は、横に並んだスキットル群の中から1本だけを狙うのに有効。

```
縦投げが有効な条件：
  - ターゲットスキットルの左右（横方向）に別のスキットルが15cm以内にある
  - ターゲットが前後（奥行き方向）には他と離れている
  - 投擲者が縦投げを習得している

縦投げが不向きな条件：
  - ターゲットの奥（投擲者から見て後ろ側）にスキットルがある
  - 投擲者が縦投げ未習得
```

## 6. 投擲者の技術レベルを考慮した戦略

### レベル定義

| レベル | 1本狙い成功率目安 | 特徴 |
|---|---|---|
| 初心者 | 30%以下 | フォーム不安定、狙いにくい |
| 中級者 | 30〜60% | 基本フォーム安定 |
| 上級者 | 60%以上 | 安定した精度、特殊技術保有 |

### 技術要素

**確実に倒せる距離**
- 投擲者ごとに「この距離以内なら高確率で当たる」距離がある
- その距離外のスキットルは成功率を大きく割り引いて評価する

**縦投げの得意・不得意**
- 縦投げ得意 → 横並び密集からの1本狙いに縦投げを推奨
- 縦投げ不得意 → 孤立したスキットルを選ぶ方向で助言

### レベル別戦略調整

**初心者**
```
序盤：密集群を狙い3〜5点を確実に積む
中盤：近い距離の中程度番号（5〜8番）を1本狙い
終盤：近くに残っている番号スキットルのみ狙う、遠ければ小番号を積み上げ
```

**中級者**
```
序盤：高得点1本狙いを基本、失敗時は密集があれば複数本に切り替え
中盤：高得点スキットルの1本狙い、巻き込みリスクを意識
終盤：必要な番号を1本狙い、2〜3番の誤差はコントロール可能として扱う
```

**上級者**
```
序盤：12 > 11 > 10 > 9の順で1本狙い徹底
中盤：妨害戦略を視野に入れる、縦投げ・ラハティ投げ等を活用
終盤：必要な番号を確実に1本で仕留める
```

## 7. 妨害戦略（インターフェレンス）

### 妨害に切り替えるトリガー

```
以下のいずれかを満たす場合に妨害を検討：

条件A（相手が上がりに近い）：
  相手スコア >= 45 AND 自分が次の1投で上がれない

条件B（大差でリードされている）：
  相手スコア >= 自スコア + 15 AND 相手スコア >= 35

条件C（自分がオーバースコア直後）：
  自スコア == 25（オーバー戻り）AND 相手スコア >= 40

→ 上記条件に該当しない場合は自スコアアップを優先
```

### 妨害優先度スコア（数値化）

```
妨害優先度 =
  (相手スコア / 50) × 60
  + (相手が次の1投で上がれる ? 40 : 0)
  + (自分が次の1投で上がれない ? 20 : 0)

妨害優先度 >= 80 → 妨害を最優先
妨害優先度 60〜79 → 自分が上がれない場合のみ妨害
妨害優先度 < 60  → 自スコアアップ優先
```

### 妨害手法1：スキットルを遠くに飛ばす

```
目的：相手が依存している高得点スキットルを難しい位置へ移動
技法：強投（ラハティ投げ）で直撃させ遠方に飛ばす
推奨条件：
  - 相手が特定の番号に強く依存している（例：相手残り12点で12番が残っている）
  - そのスキットルが現在比較的近く、かつ孤立している
  - 自チームのスキットルを巻き込まない角度がある
注意：意図しない自スキットルへの被害を避けること
```

### 妨害手法2：スキットルを密集させる（群れを作る）

```
目的：相手の1本狙いを複数本狙いに変えさせ、オーバースコアや誤差を誘う
技法：軽めの投擲で対象スキットルの隣接位置にスキットルを転がす
推奨条件：
  - 相手が高得点スキットル1本（11, 12番）を精密に狙っている
  - そのスキットルが孤立して狙いやすい状況になっている
  - 寄せに使うスキットルは自チームにとって不要な低得点スキットル
効果：相手が複数本倒してしまい、オーバースコアや低得点を誘発
```

### 妨害 vs 自スコアアップの選択例

```
例1：相手スコア=45、自スコア=30
  → 相手は次1〜2投で上がれる、自分は最低2投必要
  → 妨害優先（妨害しないと負ける）

例2：相手スコア=35、自スコア=44（残り6点）
  → 自分が次の1投で上がれる可能性が高い
  → 自スコアアップ（上がり狙い）優先

例3：相手スコア=48、自スコア=48（残り2点）
  → 両者ともに上がりが近い
  → 自スコアアップ優先（自分が先に上がることを目指す）
```

## 8. リスク管理

### 3回連続ミス（失格）の回避

```
ミスカウント == 0 → 通常戦略
ミスカウント == 1 → やや安全な目標に切り替え（精度高い目標を選ぶ）
ミスカウント == 2 → 確実に当たる最も近いスキットルを最優先
                    得点の高低より「当てること」を最優先

ミスカウント == 2 の推奨アクション：
  近距離（2m以内）にスキットルがある → そのスキットルを狙う（番号無視）
  全スキットルが遠い（3m以上）        → スキットルが多い方向を広く狙う
                                        縦方向に並んでいる列の手前を狙う
```

### オーバースコア（50点超過）の回避

```
投擲前チェックリスト：
  1. 現在のスコアを確認
  2. 狙うスキットルを1本倒した場合の加算点を計算
  3. 周囲のスキットルを巻き込んだ場合（複数本）の点数も計算
  4. いずれの場合も50点以下になる選択のみ推奨する

例：スコア = 42（残り8点）
  - 12番1本 → 42 + 12 = 54（オーバー）→ 不可
  - 9番1本  → 42 + 9 = 51（オーバー）→ 不可
  - 8番1本  → 42 + 8 = 50（ちょうど勝利）→ 最優先
  - 7番1本  → 42 + 7 = 49（次ターンへ）→ 次善
  - 3本巻き込み → 42 + 3 = 45（セーフだが低得点）
```

### 狙えるスキットルがない場合（残り点数 = N だがN番が存在しない）

```
対処法（優先順位順）：
  1. 残り点数を超えない最大番号を1本狙い（次ターンで調整）
  2. 小さい番号の組み合わせを2〜3投で達成（下表参照）
  3. 1番または2番を繰り返し狙い積み上げる（相手スコアが低い場合のみ有効）
  4. 妨害に切り替えて時間を稼ぐ（相手スコアが高い場合）
```

### 残り点数の2投完了組み合わせ表

```
残り2  → [2番1本]
残り3  → [3番1本]
残り4  → [4番1本] | [1+3]
残り5  → [5番1本] | [2+3]
残り6  → [6番1本] | [3+3] | [1+5]
残り7  → [7番1本] | [3+4] | [1+6]
残り8  → [8番1本] | [4+4] | [3+5]
残り9  → [9番1本] | [4+5] | [3+6]
残り10 → [10番1本] | [5+5] | [4+6]
残り11 → [11番1本] | [5+6] | [4+7]
残り12 → [12番1本] | [6+6] | [5+7]
残り13 → [7+6] | [5+8] | [4+9]
残り14 → [7+7] | [6+8] | [5+9]
残り15 → [8+7] | [6+9] | [5+10]
```

## 9. 複数セット試合の戦略

### セット数を考慮した方針

```
1セット制（Best of 1）：
  - 通常通りの戦略
  - 妨害は相手が40点以上になったら検討

3セット制（Best of 3）：
  第1セット → 攻撃的。リードを奪いに行く
  第2セット（リード中）→ 安全優先。オーバースコア厳禁
  第2セット（ビハインド）→ やや積極的。妨害も活用
  第3セット → 全力勝負。精度の高い狙いを最優先
```

### 先行・後攻の特性

```
先行の利点：先に上がれる可能性がある
後攻の利点：
  - 相手の動きを見てから行動できる
  - 相手がオーバースコアした直後のターンを最大限活用できる
  - 相手が上がりに近づいたら1手早く妨害できる

後攻時の追加戦術：
  - 相手スコアを常に監視
  - 相手がオーバースコアしたターン直後は積極的に得点を伸ばす（プレッシャーが減る）
```

## 10. AI助言に必要な入力情報

AI助言ロジックの品質を高めるために必要な情報の一覧。

### 現在収集している情報
- 現在の自チームスコア（各セットの累計）
- 現在の敵チームスコア
- 自チームの連続ミス数
- 現在のラウンド数 / セット数
- 試合の制限ルール（ターン制限、時間制限）

### カメラ画像から取得できる情報
- 各スキットルの立/倒状態（番号1〜12）
- スキットルのおおよその位置・散らばり具合
- 密集している番号の組み合わせ

### 今後追加を検討すべき情報

**投擲者の技術プロフィール（ユーザーが事前設定）**
```
- 確実に倒せる最大距離（例：「3m以内なら高確率」）
- 縦投げの習得有無（true / false）
- 精度レベル（初心者 / 中級者 / 上級者）
- 得意な狙い方（密集狙い、精密1本狙いなど）
```

**スキットルの配置詳細（カメラ解析の精度向上で取得）**
```
- 各スキットルの投擲ラインからの距離（m）
- 隣接スキットルとの間隔（cm）
- スキットルが縦一列に並んでいるかどうか
```

**試合状況の追加コンテキスト**
```
- 残りターン数（ターン制限ルール使用時）
- 残り時間（時間制限ルール使用時）
- 相手チームの連続ミス数
- セット数と現在のセット勝敗状況（3セット制など）
```

## 11. AI助言ロジックの判断ツリー（実装参考）

```
INPUT:
  myScore, oppScore, missCount, standingPins,
  throwerLevel, canThrowVertical, maxReliableDistance,
  currentRound, totalSets, setWins

START:
  // 最優先：失格回避
  if missCount == 2:
    → 最も近く当てやすいスキットルを狙う（番号無視）
    → EXIT

  // 上がり狙い
  remaining = 50 - myScore
  winningPin = standingPins.find(p => p == remaining)
  if winningPin exists AND 距離が信頼距離内:
    → winningPin を1本狙い（勝利）
    → EXIT

  // 妨害フェーズ判断
  interferenceScore = calcInterference(oppScore, myScore)
  if interferenceScore >= 80:
    → 妨害アクションを推奨（セクション7参照）
    → EXIT

  // 通常フェーズ
  if myScore >= 40:
    → 終盤戦略（残り点数の番号を1本狙い）
  elif myScore >= 26:
    → 中盤戦略（高得点1本狙い、オーバー除外）
  else:
    → 序盤戦略（精度に応じて1本 or 複数本）

  // 技術レベル・距離補正を加えてスキットルをスコアリング
  for each candidate in standingPins:
    score = baseScore(candidate)
    score += distanceBonus(candidate.distance, maxReliableDistance)
    score += adjacencyBonus(candidate.neighbors)
    score += verticalThrowBonus(candidate, canThrowVertical)
    score -= overscoreRisk(candidate, myScore)
  
  → 上位3件を助言として返す
```
